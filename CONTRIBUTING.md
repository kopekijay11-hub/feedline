# Contributing

Feedline is a one-developer portfolio project, published for review. Issues and discussion are welcome — questions about the design are best asked as GitHub issues, and the design-decision log in [DECISIONS.md](DECISIONS.md) records the reasoning behind the current shape.

Code contributions are by invitation only: the repository is licensed all-rights-reserved (see [LICENSE](LICENSE)), so please do not submit pull requests containing code unless the maintainer has agreed in advance.
